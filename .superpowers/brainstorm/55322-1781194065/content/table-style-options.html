终端表格样式方向

截图里的样式不是 Markdown 表格，而是终端富文本表格：边框、表头颜色、等宽字符对齐。

A. 当前风格：ASCII 边框
+--------------+------------+------+
| 标题         | 修改时间   | 链接 |
+--------------+------------+------+
| 成都三日游   | 2026-06-10 | 链接 |
+--------------+------------+------+

兼容性最好，当前 roadbook list 已经接近这个实现；cnote list 还需要接入同一套渲染。

B. 截图风格：Unicode + 表头颜色
┌──────────────┬────────────┬──────┐
│ 标题         │ 修改时间   │ 链接 │
├──────────────┼────────────┼──────┤
│ 成都三日游   │ 2026-06-10 │ 链接 │
└──────────────┴────────────┴──────┘

视觉更接近截图。需要处理 ANSI 颜色宽度、中文宽字符、超链接控制码，适合把 roadbook 和 cnote 共用一个表格渲染器。

B

推荐：Unicode 边框 + 紫色表头

最接近截图，同时保持 CLI 输出可复制、可测试。非 TTY 或不支持颜色时降级为无色。

A

保守：沿用 ASCII 边框

最稳，但不太像截图。主要工作是让 cnote list 也复用 roadbook 的表格输出。
