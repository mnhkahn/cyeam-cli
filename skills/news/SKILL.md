# AI 新闻与科技资讯

## 使用方式

### 获取新闻列表并自动总结

```bash
# 获取并自动总结最新新闻
cyeam news get
```

## 数据来源与处理流程

1. **获取原始新闻列表**：通过工具获取新闻列表（标题、链接、初步摘要）
2. **二次爬取详情**：对每条链接执行二次爬取，**微信公众号除外**（`mp.weixin.qq.com` 不爬）
3. **AI 总结提炼**：由大模型对每条新闻做中文要点提炼，控制在 100-200 字
4. **新闻打分排序**：按以下标准为每条新闻打分（0-100分），按分数降序展示

### 新闻打分标准

| 分数区间 | 新闻类型 |
|---------|---------|
| 90-100分 | 首发重大新闻、里程碑级发布 |
| 80-89分 | 重要技术进展、知名大佬核心观点、深度长文 |
| 70-79分 | 实用工具更新、有价值的教程、行业数据报告 |
| 60-69分 | 二手信息、一般性新闻、小道消息 |
| <60分 | 低价值/局部内容：纯情绪宣泄、无营养评价、广告、日常闲聊 |

每条新闻单独打分后按分数降序排列，最终输出分数最高的 8-15 条。

## 二次爬取规则

| 链接类型 | 是否爬取详情 | 说明 |
|---------|------------|------|
| 微信公众号 (mp.weixin.qq.com) | ❌ 不爬 | 反爬限制严格，直接用原始摘要 |
| 普通网页 | ✅ 爬取 | 提取标题、正文、首图，用于 AI 总结 |

## 二次爬取说明

使用可用工具获取网页详情，优先顺序：
1. 用 `curl` 获取 HTML 后自行解析标题、正文
2. 使用 agent 自带的网页抓取/访问工具

提取内容：
- 网页真实标题
- 正文纯文本（过滤导航、广告、评论）
- 首图/主图 URL（如有）

爬取失败时回退到原始摘要。

## AI 总结要求

### 输出 JSON 结构（与 API 对齐）

```json
{
  "date": "2026-06-26",
  "news": {
    "create_time": 1719331200,
    "summary": "今日科技要闻总结...",
    "news": [
      {
        "title": "新闻标题",
        "link": "https://...",
        "description": "AI提炼的要点，用\\n分隔，最多5条",
        "image": "https://.../img.jpg",
        "create_time": 1719331200
      }
    ]
  },
  "ai_news": {
    "create_time": 1719331200,
    "news": [
      {
        "title": "AI新闻标题",
        "link": "https://...",
        "description": "要点内容",
        "image": "",
        "create_time": 1719331200
      }
    ]
  }
}
```

### 字段说明

| 字段 | 说明 |
|------|------|
| `news.summary` | 全局总结，一段话概括最重要的3-5个趋势 |
| `news[].title` | 新闻标题 |
| `news[].link` | 原文链接 |
| `news[].description` | AI 提炼的要点，用 `\n` 分隔，最多5条，每条一句话 |
| `news[].image` | 首图 URL（如有，空字符串代表无） |
| `news[].create_time` | 新闻发布时间戳 |

### Markdown 展示格式

拿到 JSON 后按以下格式展示给用户：

```
## 📊 今日科技要闻总结
{{news.summary}}

## 📰 技术动向

{% for item in news.news %}
### {{item.title}}

🔗 {{item.link}}

💡 核心要点：
{{item.description | split("\n") | map: "- " + item | join("\n")}}

{% endfor %}

## 🤖 AI 资讯

{% for item in ai_news.news %}
### {{item.title}}

🔗 {{item.link}}

💡 核心要点：
{{item.description | split("\n") | map: "- " + item | join("\n")}}

{% endfor %}
```

## 适合的场景

- "今天有什么科技新闻？"
- "最近 AI 圈有什么动态？"
- "帮我总结下最新的 tech news"
- "最近有什么值得关注的开源项目发布？"

## 注意事项

- 微信公众号链接不二次爬取，直接展示原始摘要
- 二次爬取失败的链接也用原始摘要兜底
- 最终输出控制在 8-15 条新闻，过多时只保留最重要的
